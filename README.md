# rules

synced daily from upstream (QuixoticHeart, blackmatrix7, missuo).

- `rules` branch holds the rule files (`Egern/`, `Surge/`, `Clash/`).
- `master` branch holds only the sync workflow (`.github/workflows/sync.yml`),
  this README and the LICENSE.
- Served at https://hub.hin0ka.com/rules/ (see hinokka/hub.hin0ka Worker).
